# mmWave Presence Sensor Integration

## Hardware Connection
The sensor requires a 5V supply and UART communication.

| Sensor Pin | ESP32-S3-Zero Pin | Note |
| :--- | :--- | :--- |
| **VCC (5V)** | **5V** | Sensor requires $>200\text{mA}$ |
| **GND** | **GND** | Common ground |
| **TX** | **GPIO44 (RX)** | Sensor TX $\rightarrow$ ESP RX |
| **RX** | **GPIO43 (TX)** | Sensor RX $\rightarrow$ ESP TX |

::caution Warning
If you use the default UART0 (GPIO43/44), you cannot use the same pins for USB-Serial debugging simultaneously. See the Sensor Hub section for alternative mapping.

## Software Configuration
- **Baud Rate**: `256000`
- **Logic Level**: 3.3V (Compatible with ESP32-S3)

### Arduino Implementation Snippet
```cpp
#include <HardwareSerial.h>

// Using Serial1 for the sensor to keep Serial (USB) for debugging
HardwareSerial mmWaveSerial(1); 

void setup() {
  Serial.begin(115200); // USB Debugging
  // mmWaveSerial.begin(baud, config, RX_PIN, TX_PIN);
  mmWaveSerial.begin(256000, SERIAL_8N1, 1, 2); 
  Serial.println("mmWave Sensor Initialized...");
}

void loop() {
  if (mmWaveSerial.available()) {
    Serial.write(mmWaveSerial.read());
  }
}
```

## Configuration & Calibration
1. **App Setup**: Use the `HLKRadarTool` app via Bluetooth to set detection distance (0.75m ~ 6m) and sensitivity.
2. **Engineering Mode**: Use a USB-to-UART adapter (256000 baud) if configuring via PC.
3. **Recovery**: If sensor stops reporting, use the App $\rightarrow$ More $\rightarrow$ **Initialize**.
