# Sensor Hub Integration

This guide describes how to connect a multi-sensor array to a single ESP32-S3-Zero.

## Hardware Layout

### Power Rail
- **5V Rail**: ESP32 5V $\rightarrow$ mmWave VCC
- **3.3V Rail**: ESP32 3V3 $\rightarrow$ BME280 VCC, BH1750 VCC, Status LED, Buttons

### Connection Table

| Component | Component Pin | ESP32-S3-Zero Pin | Protocol / Type |
| :--- | :--- | :--- | :--- |
| **mmWave Sensor** | TX | **GPIO 1** | UART1 RX |
| | RX | **GPIO 2** | UART1 TX |
| **BME280** | SDA | **GPIO 8** | I2C SDA |
| | SCL | **GPIO 9** | I2C SCL |
| **BH1750** | SDA | **GPIO 8** | I2C SDA (Shared) |
| | SCL | **GPIO 9** | I2C SCL (Shared) |
| **Status LED** | Anode (+) | **GPIO 4** | Digital Out (via $\sim 220\Omega$) |
| **Button 1** | Pin A | **GPIO 5** | Digital In (Pull-up) |
| **Button 2** | Pin A | **GPIO 6** | Digital In (Pull-up) |

## System Architecture

### I2C Bus
The BME280 (Temp/Hum/Pres) and BH1750 (Light) share the same I2C bus on GPIO 8 and 9.

### UART Communication
The mmWave sensor is mapped to a custom UART1 (GPIO 1/2) to prevent interference with the native USB-Serial debugging port (GPIO 43/44).

## Schematic Diagram
```text
[5V] ───────> mmWave VCC
[3.3V] ──┬──> BME280 VCC ──┬──> BH1750 VCC ──┬──> LED (+) ──┬──> Buttons
         │                 │                 │              │
[GND] ───┴──> All GNDs ────┴─────────────────┴──────────────┴─────
[GPIO 1] <── mmWave TX
[GPIO 2] ──> mmWave RX
[GPIO 8] <──> BME280 SDA <──> BH1750 SDA
[GPIO 9] <──> BME280 SCL <──> BH1750 SCL
[GPIO 4] ──> LED (-) via Resistor
[GPIO 5] <── Button 1
[GPIO 6] <── Button 2
```
