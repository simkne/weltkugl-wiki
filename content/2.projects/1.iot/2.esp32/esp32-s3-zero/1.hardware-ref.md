# ESP32-S3-Zero Hardware Reference

## Core Specifications
- **MCU**: ESP32-S3FH4R2 (Xtensa® 32-bit LX7 dual-core, up to 240MHz)
- **Memory**: 4MB Flash, 2MB PSRAM
- **Wireless**: 2.4GHz Wi-Fi, Bluetooth 5 (LE)
- **USB**: Type-C (Native USB, no USB-to-UART chip)
- **RGB LED**: WS2812 connected to **GPIO21**

::tip Note
The ESP32-S3-Zero uses a native USB port. For `Serial.println()` to work in Arduino, you must enable **"USB CDC On Boot"** in the Tools menu.

## Power
- **Input**: 3.7V ~ 6V via 5V pin or Type-C USB.
- **Current**: Requires at least 500mA when powered via 5V.
- **Regulator**: Onboard 3.3V LDO (up to 800mA).

## Pinout & Interface
- **UART0 (Default)**: 
    - TX: **GPIO43**
    - RX: **GPIO44**
- **Boot Mode**: Hold BOOT (GPIO0) while connecting USB to enter download mode.
- **Reserved**: GPIO33 ~ GPIO37 (used for Octal PSRAM).
