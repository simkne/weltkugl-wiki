## TL;DR

The five commands you'll use most often:

```bash
# 1. Check if OpenHAB is running
sudo systemctl status openhab

# 2. Watch live logs
sudo tail -f /var/log/openhab/openhab.log

# 3. Clean restart (fixes 80 % of weird behaviour)
sudo systemctl stop openhab
sudo rm -rf /var/lib/openhab/cache/* /var/lib/openhab/tmp/*
sudo systemctl start openhab

# 4. Backup configuration
sudo openhab-cli backup

# 5. Quick health overview
alias ohhealth='echo "=== OpenHAB ===" && sudo systemctl is-active openhab && echo "=== Disk ===" && df -h / && echo "=== Memory ===" && free -h | grep Mem && echo "=== Last Error ===" && sudo grep -i error /var/log/openhab/openhab.log | tail -n 1'
```

Replace `<PI_IP>` everywhere below with your Pi's actual address (e.g. `192.168.1.23`).

## Key filesystem paths

| What | Path | Notes |
|------|------|-------|
| **Items** | `/etc/openhab/items/` | `.items` files |
| **Things** | `/etc/openhab/things/` | `.things` files |
| **Rules** | `/etc/openhab/rules/` | `.rules` or UI rules |
| **Scripts** | `/etc/openhab/scripts/` | `.script` files |
| **Transform** | `/etc/openhab/transform/` | MAP, JS, regex transforms |
| **Persistence** | `/etc/openhab/persistence/` | rrd4j, InfluxDB configs |
| **Services** | `/etc/openhab/services/` | Addon configs (MQTT, etc.) |
| **Sitemaps** | `/etc/openhab/sitemaps/` | Classic UI sitemaps |
| **Main UI widgets** | `/etc/openhab/ui/` | YAML widget backups |
| **Log files** | `/var/log/openhab/` | `openhab.log`, `events.log` |
| **OpenHAB config (UI)** | `/var/lib/openhab/config/` | JSON DB — **do not edit by hand** |
| **Userdata** | `/var/lib/openhab/` | Persistence DBs, cache |
| **Backup dir** | `/var/lib/openhab/backups/` | `.zip` config exports |

## Essential commands

### Service control

```bash
sudo systemctl status openhab        # is it running?
sudo systemctl restart openhab       # restart
sudo systemctl stop openhab          # stop
sudo systemctl start openhab         # start
sudo systemctl enable openhab        # auto-start on boot
```

### View logs (live)

```bash
sudo tail -f /var/log/openhab/openhab.log
sudo tail -f /var/log/openhab/events.log

# Both at once
sudo tail -f /var/log/openhab/*.log

# Filter for errors only
sudo grep -i error /var/log/openhab/openhab.log
```

### OpenHAB console (Karaf)

```bash
openhab-cli console
# password: see openHABian docs (default is well-documented — change it!)

# Useful console commands:
> bundle:list                  # list all bindings/addons
> log:tail                     # live log
> log:set DEBUG org.openhab.binding.mqtt
> log:set INFO org.openhab.binding.mqtt
> restart                      # restart openhab from within
> logout                       # exit console
```

### Configuration backup / restore

```bash
# Create backup (produces a zip in /var/lib/openhab/backups/)
sudo openhab-cli backup

# Backup with custom filename
sudo openhab-cli backup /home/openhabian/my-backup.zip

# Restore from backup
sudo openhab-cli restore /var/lib/openhab/backups/openhab-backup-20XX-XX-XX.zip

# List backups
ls -lah /var/lib/openhab/backups/
```

### System updates

```bash
# Update package lists
sudo apt update

# Upgrade OpenHABian + system packages
sudo apt upgrade

# Interactive config tool (safer path)
sudo openhabian-config
```

**`openhabian-config` menu cheatsheet:**

| Option | What it does |
|--------|--------------|
| `01` Update | Update the openhabian tool itself |
| `02` Upgrade System | `apt upgrade` |
| `03` OpenHAB Stable | Install / upgrade OpenHAB |
| `10` Apply Improvements | Fix permissions, Samba, etc. |
| `20` Optional Components | Install frontail, zigbee2mqtt, etc. |
| `30` System Settings | Timezone, password, WiFi |
| `50` Backup/Restore | Amanda backup system |

### Check disk space and health

```bash
df -h                    # disk usage
free -h                  # RAM usage
du -sh /var/log/openhab  # log folder size

# Clear old logs (careful)
sudo journalctl --vacuum-time=7d
sudo find /var/log/openhab -name "*.log.*" -mtime +7 -delete
```

### File permissions

OpenHAB runs as user `openhab`. If you copy files via SSH, fix ownership:

```bash
sudo chown -R openhab:openhab /etc/openhab/
sudo chmod -R 644 /etc/openhab/items/*.items
sudo chmod -R 644 /etc/openhab/things/*.things
sudo chmod -R 644 /etc/openhab/rules/*.rules

# After changes, restart
sudo systemctl restart openhab
```

### MQTT broker (Mosquitto)

```bash
sudo systemctl status mosquitto
sudo systemctl restart mosquitto

# Test broker locally
mosquitto_sub -h localhost -t "#" -v

# Test specific topic
mosquitto_sub -h localhost -t "home/office/+/temperature" -v
```

### Samba share (Windows / macOS access)

OpenHABian exposes `/etc/openhab/` and `/var/log/openhab/` via Samba.

```bash
# Check samba status
sudo systemctl status smbd
```

**Default share paths:**

| From macOS / Windows | Maps to |
|----------------------|---------|
| `smb://<PI_IP>/openHAB-conf` | `/etc/openhab/` |
| `smb://<PI_IP>/openHAB-log` | `/var/log/openhab/` |
| `smb://<PI_IP>/openHAB-userdata` | `/var/lib/openhab/` |

### Clean restart sequence

If OpenHAB is acting up, do a clean restart:

```bash
sudo systemctl stop openhab
sudo rm -rf /var/lib/openhab/cache/*
sudo rm -rf /var/lib/openhab/tmp/*
sudo systemctl start openhab

# Watch logs
sudo tail -f /var/log/openhab/openhab.log
```

## Scheduled maintenance checklists

Tick off tasks as you go. Run the reference commands above when needed.

### Daily — Quick health check (2 min)

- [ ] OpenHAB web UI loads at `http://<PI_IP>:8080/`
- [ ] All Things show **Online** (*Settings → Things*)
- [ ] No error banners in Main UI
- [ ] Recent `events.log` activity (last entry within expected interval)

```bash
# One-liner
ssh openhabian@<PI_IP> "sudo tail -n 5 /var/log/openhab/events.log"
```

### Weekly — Log & disk review (10 min)

- [ ] Check `openhab.log` for ERROR or WARN spikes
  ```bash
  sudo grep -ci error /var/log/openhab/openhab.log
  sudo grep -ci warn /var/log/openhab/openhab.log
  ```
- [ ] Review `events.log` — any unexpected Item changes or rule loops?
- [ ] Disk usage under 80 %
  ```bash
  df -h
  ```
- [ ] RAM usage normal (not swapping constantly)
  ```bash
  free -h
  ```
- [ ] Mosquitto broker running
  ```bash
  sudo systemctl status mosquitto
  ```
- [ ] `zram` status healthy (if enabled)
  ```bash
  zramctl
  ```

### Monthly — Updates & cleanup (30 min)

- [ ] **Backup configuration**
  ```bash
  sudo openhab-cli backup
  ls -lah /var/lib/openhab/backups/
  ```
  Copy the `.zip` off the Pi to your workstation:
  ```bash
  scp openhabian@<PI_IP>:/var/lib/openhab/backups/openhab-backup-*.zip ~/Backups/OpenHAB/
  ```
- [ ] **Update package lists**
  ```bash
  sudo apt update
  ```
- [ ] **Upgrade system packages** (if comfortable)
  ```bash
  sudo apt upgrade
  ```
  Or the safer interactive path: `sudo openhabian-config` → `02 | Upgrade System`
- [ ] **Review and delete old logs**
  ```bash
  sudo journalctl --vacuum-time=14d
  sudo find /var/log/openhab -name "*.log.*" -mtime +14 -delete
  ```
- [ ] **Check for orphaned Items** (no linked channel) — *Settings → Items*
- [ ] **Verify rule UIDs are unique**
  ```bash
  grep -rh "^uid:" /etc/openhab/rules/ | sort | uniq -d
  ```
  *(Any output = duplicate UIDs causing conflicts.)*
- [ ] **Test one automation end-to-end** (e.g. flip a plug, confirm state updates in UI)
- [ ] **Restart OpenHAB clean** (optional, if sluggish)
  ```bash
  sudo systemctl stop openhab
  sudo rm -rf /var/lib/openhab/cache/* /var/lib/openhab/tmp/*
  sudo systemctl start openhab
  ```

### Quarterly — Deeper review (45 min)

- [ ] **Full OpenHABian config review**
  ```bash
  sudo openhabian-config
  ```
  Run: `01 | Update`, `10 | Apply Improvements`
- [ ] **Check binding versions** — any outdated or deprecated? (*Settings → Add-ons → Bindings*)
- [ ] **Review persistence data** — is `rrd4j` or InfluxDB growing unbounded?
  ```bash
  du -sh /var/lib/openhab/persistence/
  ```
- [ ] **Audit Things** — remove old / unused Things
- [ ] **Audit Items** — remove orphaned Items
- [ ] **Audit rules** — disable or delete rules for devices no longer in use
- [ ] **Verify Z-Wave / Zigbee mesh health** (if applicable)
  - Check controller stick recognized: `sudo dmesg | grep -i usb`
  - Review battery levels of battery-powered nodes
- [ ] **Review network health** — static IPs still valid? Router DHCP reservations intact?
- [ ] **Check SD card wear** (if running on SD, not SSD)
  ```bash
  sudo apt install smartmontools  # if not present
  sudo smartctl -a /dev/mmcblk0   # look for reallocated sectors / wear
  ```
- [ ] **Copy one backup off-site** — USB drive, cloud, or second Pi

### Yearly — Infrastructure refresh (2–3 h)

- [ ] **Full SD card / SSD image backup**
  ```bash
  # From your workstation, with SD card in reader
  sudo dd if=/dev/rdisk2 of=~/Backups/openhabian-$(date +%Y-%m-%d).img bs=1m
  ```
- [ ] **Major OpenHAB version upgrade** (e.g. 5.1 → 5.2)
  - Read release notes first
  - Backup config
  - Test in a sandbox if possible
  - Use `sudo openhabian-config` → `03 | OpenHAB Stable`
- [ ] **Rotate passwords**
  - `openhabian` user SSH password
  - Samba shares password
  - OpenHAB console password (change in `users.properties`)
  - MQTT broker credentials (if any)
- [ ] **Review and update documentation**
  - Confirm IP addresses, device names, Thing UIDs still accurate
  - Update network diagram / inventory
- [ ] **Hardware check**
  - Pi temperature: `vcgencmd measure_temp`
  - Power supply voltage: `vcgencmd get_throttled` (should show `0x0`)
  - Clean dust from case / fan
  - Check cable connections (USB sticks, ethernet)
- [ ] **Renew SSL certificates** (if using reverse proxy / Let's Encrypt)
  ```bash
  sudo certbot renew --dry-run
  ```
- [ ] **Test disaster recovery** — restore a backup `.zip` to a fresh install and verify

### Ad-hoc — when something breaks

| Symptom | First check | Likely fix |
|---------|-------------|------------|
| Web UI won't load | `sudo systemctl status openhab` | Restart service, check `openhab.log` |
| All Things offline | `sudo systemctl status mosquitto` | Restart Mosquitto, check WiFi / router |
| High CPU | `top` | Identify binding loop, restart OpenHAB |
| Disk full | `df -h` | Delete old logs, clear cache / tmp |
| Rules not firing | `sudo grep -i rule /var/log/openhab/openhab.log` | Check for duplicate UIDs, syntax errors |
| Z-Wave nodes dead | `sudo dmesg \| grep -i usb` | Re-plug stick, heal network |
| Widgets blank / broken | Browser F12 console | Clear cache, check Item names |
| MQTT topics missing | `mosquitto_sub -h localhost -t "#" -v` | Check device WiFi, broker config |

## Persistence & data maintenance

OpenHAB stores historical data for charts, trends, and rule logic. Without maintenance, persistence databases grow forever and slow down the system.

### rrd4j (default, pre-installed)

| Task | Command / Action |
|------|----------------|
| Check size | `du -sh /var/lib/openhab/persistence/rrd4j/` |
| Auto-cleanup | Built-in — rrd4j is round-robin, fixed size per Item |
| Rebuild corrupt DB | Stop OpenHAB, delete `.rrd` file for the Item, restart |
| Change retention | Edit `/etc/openhab/persistence/rrd4j.persist` |

**rrd4j default strategy:** `everyMinute` for numeric Items. This is fine for sensors, but wasteful for slow-changing Items (e.g. a Switch that changes once a day).

**Optimization:** Use different strategies per Item group:

```java
// /etc/openhab/persistence/rrd4j.persist
Strategies {
    everyMinute : "0 * * * * ?"
    everyHour   : "0 0 * * * ?"
    everyDay    : "0 0 0 * * ?"
}

Items {
    gSensors*     : strategy = everyMinute    // temp, humidity, power
    gSwitches*    : strategy = everyChange     // on/off — no need for everyMinute
    gEnergy*      : strategy = everyHour       // cumulative kWh — hourly is enough
}
```

### InfluxDB (if installed)

| Task | Command |
|------|---------|
| Check DB size | `influx -execute 'SHOW DATABASES'` then `du -sh /var/lib/influxdb/` |
| List measurements | `influx -database openhab -execute 'SHOW MEASUREMENTS'` |
| Query last point | `influx -database openhab -execute 'SELECT last(*) FROM "Zensoria02_Temperature"'` |
| Retention policy | `influx -execute 'SHOW RETENTION POLICIES ON openhab'` |
| Set retention (e.g. 1 year) | `influx -execute 'CREATE RETENTION POLICY one_year ON openhab DURATION 52w REPLICATION 1 DEFAULT'` |
| Drop old data manually | `influx -database openhab -execute 'DELETE FROM "SomeOldItem" WHERE time < now() - 30d'` |

**Monthly InfluxDB maintenance:**

```bash
# Check if DB is getting large
sudo du -sh /var/lib/influxdb/data/openhab/

# Set a retention policy and let InfluxDB auto-delete
sudo influx -execute 'CREATE RETENTION POLICY one_year ON openhab DURATION 52w REPLICATION 1 DEFAULT'
```

### Disable persistence for unneeded Items

Every persisted Item = disk writes + CPU. Audit your `.persist` files:

```bash
cat /etc/openhab/persistence/rrd4j.persist
cat /etc/openhab/persistence/influxdb.persist  # if using InfluxDB
```

Remove Items that don't need history:
- Uptime counters
- WiFi SSID strings
- IP addresses
- Availability switches

### Safe cleanup script

Save as `/home/openhabian/cleanup.sh`:

```bash
#!/bin/bash
# Safe monthly cleanup

echo "Cleaning old backups..."
find /var/lib/openhab/backups -name "openhab-backup-*.zip" -mtime +14 -delete

echo "Cleaning old logs..."
find /var/log/openhab -name "*.log.*" -mtime +14 -delete
journalctl --vacuum-time=14d

echo "APT cleanup..."
apt clean
apt autoremove -y

echo "Disk usage after cleanup:"
df -h /
```

Make executable and run:

```bash
chmod +x /home/openhabian/cleanup.sh
sudo /home/openhabian/cleanup.sh
```

### Rebuild corrupt persistence data

If an Item's chart shows flat lines or gaps:

```bash
# Stop OpenHAB
sudo systemctl stop openhab

# For rrd4j: delete the corrupt .rrd file
sudo rm /var/lib/openhab/persistence/rrd4j/Zensoria02_Temperature.rrd

# Start OpenHAB — file will be recreated on next persistence write
sudo systemctl start openhab
```

### Optional: automate daily backup

```bash
# Add to crontab
sudo crontab -e

# Daily 3 AM backup
0 3 * * * /usr/bin/openhab-cli backup >/dev/null 2>&1

# Keep only last 14 backups
0 4 * * * find /var/lib/openhab/backups -name "openhab-backup-*.zip" -mtime +14 -delete
```

## Configuration best practices

### Use Item Groups for cleaner rules

Instead of updating each device individually, use Groups:

```java
// Items file
Group gSensors
Group gPlugs
Group gOnlineItems

Number:Temperature Zensoria01_Temperature "Temp [%.1f °C]" (gSensors)
Number:Temperature Zensoria02_Temperature "Temp [%.1f °C]" (gSensors)
Switch Plug01_Switch "Plug 01" (gPlugs)
Switch Plug02_Switch "Plug 02" (gPlugs)
```

Then one rule handles the whole group:

```java
rule "Any sensor offline"
when
    Member of gOnlineItems changed to OFF
then
    logInfo("Alerts", triggeringItem.name + " went offline!")
end
```

### Name Things and Items consistently

| Pattern | Example |
|---------|---------|
| `Location_Type_Function` | `Office_Sensor_Temperature` |
| `DeviceName_Online` | `Zensoria02_Online` |
| `DeviceName_Function` | `ShellyPlug01_Power` |

Avoid spaces in Item names. Use CamelCase or underscores.

### Tag Items for the semantic model

In OpenHAB 3 / 4 / 5, tagging Items enables:
- Auto-generated overview cards
- Voice assistant integration (Alexa / Google)
- Location-based grouping

```java
Number:Temperature LivingRoom_Temperature "Living Room Temp" <temperature> ["Measurement", "Temperature"] { channel="..." }
```

Common tags: `Measurement`, `Temperature`, `Humidity`, `Setpoint`, `Switch`, `Light`.

### Use `displayState` in widgets

Always prefer `items[props.item].displayState` over `.state` in widgets. It respects:
- Item formatting (`%.1f °C`)
- MAP transformations
- Unit of measurement

### Consolidate rules — avoid one rule per device

**Bad:** 5 identical rules for 5 sensors.
**Good:** 1 rule using `Member of` trigger.

Example — one online-status rule for ALL ESPHome devices:

```java
rule "Any ESPHome device status"
when
    Member of gESPHomeThings changed
    or System started
then
    val thingUID = triggeringItem.name.replace("_", ":").replace("ThingStatus", "")
    // ... update corresponding Online Item
end
```

Or better: use a single rule per device type (safer, easier to debug).

### Use metadata for widget hints

```java
Number:Temperature Zensoria02_Temperature "Temp" <temperature> {
    channel="...",
    listWidget="oh-label-item" [icon="thermometer", action="analyzer"],
    cellWidget="oh-label-cell" [icon="thermometer"]
}
```

This controls how the Item appears in auto-generated lists and cells without custom widgets.

### Audit unused bindings

```bash
# In Karaf console
openhab-cli console
> bundle:list | grep -i active
```

If a binding is installed but no Things use it, uninstall it to save RAM.

*Settings → Add-ons → Bindings → uninstall unused.*

### Enable debug logging only when needed

```bash
# In Karaf console
log:set DEBUG org.openhab.binding.mqtt
# ... debug something ...
log:set INFO org.openhab.binding.mqtt
```

Leaving DEBUG on permanently fills logs and wears the SD card.

```bash
alias ohlog='sudo tail -f /var/log/openhab/openhab.log'
alias ohevents='sudo tail -f /var/log/openhab/events.log'
alias ohrestart='sudo systemctl restart openhab'
alias ohstatus='sudo systemctl status openhab'
```

Then reload:

```bash
source ~/.bashrc
```

## File transfer from Mac / Linux

```bash
# Copy files TO the Pi
scp /local/path/to/file.items openhabian@<PI_IP>:/etc/openhab/items/

# Copy entire folder
scp -r /local/path/to/rules/ openhabian@<PI_IP>:/etc/openhab/

# Then fix permissions and restart
ssh openhabian@<PI_IP> "sudo chown -R openhab:openhab /etc/openhab/ && sudo systemctl restart openhab"
```
