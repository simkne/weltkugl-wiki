## Our stack at a glance

| Layer | Technology | Role |
|-------|------------|------|
| Hub | Raspberry Pi 4 (8 GB RAM) | Hardware host |
| OS | OpenHABian (Debian-based) | Pre-configured Linux with openHAB, Mosquitto, Samba |
| Automation | openHAB 5.x | Core platform — Things, Items, Rules, UI |
| Messaging | MQTT (Mosquitto) | Lightweight pub/sub between ESP32 nodes and openHAB |
| Custom devices | ESP32-S3, ESP32-C6 | Self-built sensor nodes — temperature, humidity, presence, etc. |
| Firmware | ESPHome / PlatformIO | Build, flash, and OTA-update ESP devices |
| Commercial | Shelly, Tasmota | Off-the-shelf smart plugs and switches |
