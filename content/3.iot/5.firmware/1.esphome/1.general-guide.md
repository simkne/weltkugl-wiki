# ESPHome Guide

ESPHome is used for rapid prototyping and deploying stable sensor nodes without writing full C++ firmware.

## General Flashing Workflow

### 1. Prerequisites
- **ESPHome CLI**: Installed via `pip install esphome`
- **Drivers**: CH340 or CP2102 USB drivers installed.
- **Secrets**: Always use a `secrets.yaml` file for Wi-Fi SSID, passwords, and API keys.

### 2. First Flash (USB)
1. Connect the device via USB.
2. Run the run command:
   ```bash
   esphome run your_device.yaml
   ```
3. Pick the correct serial port (e.g., `/dev/cu.usbserial-xxx` on macOS).
4. **Boot Mode**: For some boards (like ESP8266), you may need to hold the **FLASH** button, tap **RST**, then release **FLASH** to enter bootloader mode.

### 3. OTA Updates
After the first successful USB flash, you can update the device over the air:
```bash
esphome run your_device.yaml
```
The CLI will prefer the network (OTA) over USB.

## Useful Commands
| Command | Purpose |
| :--- | :--- |
| `esphome config file.yaml` | Validate YAML syntax |
| `esphome compile file.yaml` | Build firmware without uploading |
| `esphome logs file.yaml` | View real-time device logs (Serial/Network) |
