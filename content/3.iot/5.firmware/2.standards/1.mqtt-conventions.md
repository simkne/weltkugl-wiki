# MQTT Conventions

This document defines the standard topic and payload schemas for all ESP32-based devices in the home setup to ensure consistency across different sensors and actuators.

## Topic Schema

### Base Pattern
`home/<location>/<device>/<channel>`

- **location**: Physical or logical location (e.g., `livingroom`, `bedroom`, `kitchen`, `office`).
- **device**: Short device identifier (e.g., `envsensor`, `multisensor`, `switch1`, `plug01`).
- **channel**: Specific sensor, state, or command (e.g., `temperature`, `humidity`, `state`, `cmd`, `power`, `battery`).

**Examples:**
- `home/livingroom/envsensor/temperature`
- `home/bedroom/multisensor/motion`
- `home/office/plug01/cmd`

### Reserved Channels
| Channel | Payload Type | Description |
| :--- | :--- | :--- |
| `temperature` | Float | °C |
| `humidity` | Float/Int | %RH |
| `pressure` | Float | hPa |
| `illuminance` | Float | lux |
| `motion` | Binary | `0` (no motion) / `1` (motion detected) |
| `contact` | Binary | `0` (closed) / `1` (open) |
| `state` | String | `ON` / `OFF` |
| `cmd` | String | `ON` / `OFF` / `TOGGLE` |
| `battery` | Integer | Percentage `0–100` |
| `rssi` | Integer | WiFi RSSI in dBm |

## Payload Schema

### Simple Payloads
For most sensor readings, use single raw values:
- **Numeric**: `23.5`, `1013.2`
- **Binary**: `0` or `1`
- **State**: `ON` or `OFF`

### Complex Payloads (JSON)
For multi-value messages, use JSON with a schema version:

```json
{
  "v": 1,
  "ts": 1710000000,
  "values": {
    "temperature": 23.4,
    "humidity": 55.1
  },
  "meta": {
    "fw": "envsensor-1.0.0"
  }
}
```

- **`v`**: Schema version (Mandatory for JSON).
- **`ts`**: UNIX timestamp or ISO 8601 string.
- **`values`**: Grouped sensor readings.
- **`meta`**: Metadata (firmware, battery, RSSI).

## Device Information
Every device must expose an info topic:
`home/<location>/<device>/info`

**Payload (JSON):**
```json
{
  "v": 1,
  "device_id": "envsensor01",
  "location": "livingroom",
  "model": "esp32-env",
  "fw": "envsensor-1.0.0"
}
```

## OpenHAB Integration
- Bind **channels** using the MQTT binding.
- Use `Number` or `Switch` items for simple topics.
- Use **JSONPATH** or JS transforms for complex JSON payloads.
