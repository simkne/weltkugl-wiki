# ESP32-C6-GEEK Reference

## Overview
The ESP32-C6-GEEK is used as a development and sensor benching platform.

### Vendor Resources
- **Wiki**: [Waveshare ESP32-C6-GEEK](https://docs.waveshare.com/ESP32-C6-GEEK)

## Firmware Architecture
The device typically runs a custom firmware developed in PlatformIO with the following features:

- **Display**: ST7789 LCD using **LVGL 8** via `espressif/esp_lvgl_port`.
- **UI Logic**: Three screens (Status, I2C Bench, Help) toggled via the **Boot Button (GPIO9)**.
- **Connectivity**: Wi-Fi STA with DHCP. RSSI is monitored and displayed on the status screen.

### Key Software Entry Points
| File | Purpose |
| :--- | :--- |
| `src/main.c` | Main loop, screen management, and button mapping. |
| `src/i2c_sensor_hub.c` | Implementation of the I2C sensor bench reporting. |
| `src/sensor_bench_config.h` | Pin definitions and sensor address configurations. |
| `src/wifi_station.c` | Wi-Fi connection and reconnection policies. |

::tip Development Note
To avoid linker clashes with ESP-IDF `libnet80211`, the Wi-Fi initialization entry point is renamed to `wifi_sta_app_start`.

## Hardware Notes
- **Boot Button**: GPIO9.
- **Flash**: Large factory slot configuration is required for LVGL.
- **Target**: `esp32c6`.
