# ESP32-S3-RLCD Reference

## Overview
The ESP32-S3-RLCD-4.2 is an AIoT development board featuring a **4.2" fully reflective RLCD** (resolution 300x400).

### Key Features
- **Audio**: Onboard ES7210 (mic ADC) and ES8311 audio codec with dual microphones and speaker connector.
- **Sensors**: SHTC3 (temp/humidity) and PCF85063 (RTC).
- **Power**: 18650 battery holder with integrated charge/discharge management.
- **Connectivity**: Wi-Fi, BLE, and TF card slot.

## Power Management
The board uses the **ETA6096 / ETA6098** switching Li-ion charger family.

### Indicators
| LED | Meaning |
| :--- | :--- |
| **CHG** | Turns off when battery is fully charged. |
| **WRN** | Stays on if battery is reverse-connected. |

### Battery Monitoring (Firmware)
Battery level is read via **ADC1 channel 3**.
- **Divider Math**: $\text{voltage} = 0.001 \times \text{raw\_value} \times 3$
- **Mapping**: $3.0\text{V} \dots 4.12\text{V} \rightarrow 0\dots100\%$
