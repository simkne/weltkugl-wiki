## Overview
The ESP32-S3-RLCD-4.2 is an AIoT development board featuring a **4.2" fully reflective RLCD** (resolution 300x400).

### Key Features
- **Audio**: Onboard ES7210 (mic ADC) and ES8311 audio codec with dual microphones and speaker connector.
- **Sensors**: SHTC3 (temp/humidity) and PCF85063 (RTC).
- **Power**: 18650 battery holder with integrated charge/discharge management.
- **Connectivity**: Wi-Fi, BLE, and TF card slot.

## Board layout

1. **ESP32-S3-WROOM-1-N16R8** — SoC with Wi-Fi and Bluetooth, 240 MHz main frequency, 16 MB flash and 8 MB PSRAM.
2. **ES7210** — ADC for the echo-cancellation circuit.
3. **ES8311** — Low-power audio codec.
4. **BOOT** — Hold while powering on to enter download mode.
5. **PWR** — Long press to power off, short press to power on.
6. **KEY** — Customizable for other functions.
7. **SHTC3** — Temperature and humidity sensor for ambient monitoring.
8. **PCF85063** — RTC with timekeeping.
9. **MX1.25 2-pin speaker header** — Audio output for an external speaker.
10. **RTC battery header** — PH1.0 header for a rechargeable RTC battery only.
11. **2×8 pin 2.54 mm female header** — GPIO breakout.
12. **18650 holder** — Lithium battery holder.
13. **Dual-microphone array** — MIC1 and MIC2, paired with the ES7210 for echo cancellation.
14. **CHG** — Charging indicator. Off when the battery is fully charged.
15. **WRN** — Warning indicator. Stays on when the battery is reverse-connected.
16. **USB-C** — Programming and log output.
17. **TF card slot** — FAT32 card for extra storage.

| Function | Pins |
| :--- | :--- |
| **RLCD** | DS GPIO5, TE GPIO6, SCK GPIO11, DIN GPIO12, CS GPIO40, RESET GPIO41 |
| **SHTC3** | I²C SDA GPIO13, SCL GPIO14 |
| **PCF85063** | I²C SDA GPIO13, SCL GPIO14, interrupt GPIO15 |
| **ES8311 + ES7210** | I²S data out GPIO8, BCLK GPIO9, ADC data GPIO10, MCLK GPIO16, LRCLK GPIO45, amp enable GPIO46 |
| **TF card** | CMD GPIO21, CLK GPIO38, DATA GPIO39, card detect GPIO17 (marked NC) |
| **Buttons** | BOOT GPIO0, KEY GPIO18. PWR is the power switch. |
| **Battery** | GPIO4, ADC1 channel 3, through a 3× divider |

The 2×8 header breaks out 3V3, GND, VBUS, and GPIO0–3, GPIO13–14, GPIO17–20, and UART0 on GPIO43/44. Rotate the header view 90° clockwise to match the silkscreen in the diagram.

With ESPHome installed, these pins drive a climate display, a battery gauge, and voice. See [ESPHome on the RLCD](/iot/mcus/esp32/esp32-s3-rlcd/esphome).

## Power Management
The board uses the **ETA6096 / ETA6098** switching Li-ion charger family.

### Indicators
| LED | Meaning |
| :--- | :--- |
| **CHG** | Turns off when battery is fully charged. |
| **WRN** | Stays on if battery is reverse-connected. |

### Battery Monitoring (Firmware)
Battery level is read via **ADC1 channel 3**.
- **Divider Math**: $\text{voltage} = 0.001 \times \text{raw\_value} \times 3$
- **Mapping**: $3.0\text{V} \dots 4.12\text{V} \rightarrow 0\dots100\%$
