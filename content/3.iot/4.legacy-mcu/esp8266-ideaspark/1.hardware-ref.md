# ESP8266 IdeaSpark Reference

The IdeaSpark board is a legacy MCU used for basic sensor nodes. It features a built-in 0.96" OLED (SSD1306).

## OLED Hardware
- **Resolution**: 128x64 pixels.
- **Address**: Typically `0x3C`.
- **Wiring**: The built-in OLED is routed to **GPIO12/GPIO14**.

### Pinout Variants
Depending on the board revision, the SDA/SCL pins may be swapped:
- **Variant A (Silkscreen)**: SDA = GPIO12, SCL = GPIO14.
- **Variant B (Swapped)**: SDA = GPIO14, SCL = GPIO12.

## I2C & WiFi Coexistence
The ESP8266 uses **software (bit-banged) I2C**, which is fragile when the WiFi radio is active.

### Stability Fixes
To prevent `Communication failed` errors on the OLED:
- **Frequency**: Set I2C frequency to **10kHz**.
- **Priority**: Initialize the display **before** starting WiFi.
- **Interval**: Increase sensor update intervals (e.g., to 5s) to reduce bus traffic.
- **Bus Count**: Use a **single I2C bus** for all devices; multiple software buses are unstable.

## Integrating BMP180
When adding a BMP180 sensor:
1. **Shared Bus (Recommended)**: Wire BMP180 to GPIO12/14. Since it uses address `0x77` and OLED uses `0x3C`, they coexist perfectly.
2. **Separate Bus (Experimental)**: Wiring to D1/D2 (GPIO4/5) requires a second I2C bus in ESPHome, which is often flaky on ESP8266.

### ESPHome Config Snippet (Shared Bus)
```yaml
i2c:
  sda: GPIO12
  scl: GPIO14
  frequency: 10kHz

sensor:
  - platform: bmp085
    temperature:
      name: "Temperature"
    pressure:
      name: "Pressure"
    address: 0x77
```
